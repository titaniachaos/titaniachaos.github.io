# Originals

Masters that the published images were cut from, kept in the repository and
**out of `docs/public`**, which is published wholesale.

| File | Was |
| --- | --- |
| `titania-chaos.webp` | 1452×1800, the source of `titania-chaos-card.jpg` (1200×630) and `titania-chaos-hero.webp` (800×992) |
| `titania-portrait.jpg` | 384×684, the About page portrait before `titania-juggling.jpg` replaced it |

Anything placed here ships nowhere. To publish one, move it into
`docs/public/images/` and declare its real dimensions in `IMAGES` in
`docs/.vitepress/seo.ts` — `npm run check:images` compares the two.
